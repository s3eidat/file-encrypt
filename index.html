File Encrypt

Password-protect any file with AES-256-GCM. The file is processed in your browser in 4 MB chunks and never uploaded. Decrypting restores the original file and name.

AES-256-GCM · PBKDF2-SHA256 · 600,000 rounds

3. Result

Pick a file and a password to start.

Lose the password, lose the file. There is no reset and no back door. The password is never stored, so nobody can recover it. Keep the original until you've checked that the encrypted copy opens.
  • Each file gets its own random salt, so its own key.
  • Every 4 MB chunk is authenticated with its position and a last-chunk flag: changed, reordered or cut-off files are rejected.
  • Decrypted data is only handed over after every chunk checks out.
